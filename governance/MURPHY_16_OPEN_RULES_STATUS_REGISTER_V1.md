# Murphy 16 Open Rules — Status Register V1

## Purpose
This is the canonical deferral register for the 16 Murphy rules that remain open after the 35-rule evidence reconciliation. These rules are intentionally not to be reopened casually or treated as forgotten work. Each requires the recorded missing primitive, contract, implementation, data source, or QA evidence before closure.

## Global invariants
1. 2025 is OOS and must never be used for tuning.
2. Source semantics alone do not equal a production-frozen evaluator.
3. Existing project knowledge/modules must be audited before any new implementation.
4. No invented thresholds, tolerances, timeframes, periods, or breadth proxies.
5. This register is a defer-and-continue control: these 16 rules should not block progress on the rest of the Decision Brain unless a dependency requires one of them.
