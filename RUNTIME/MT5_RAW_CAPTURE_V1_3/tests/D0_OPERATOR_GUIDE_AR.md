# دليل تشغيل اختبار D0 — بالعربية

## قبل التشغيل

- استخدم نسخة MT5 منفصلة/ملف تعريف تجريبي مع حساب Demo فقط.
- لا تستخدم حسابًا حقيقيًا.
- لا توقف أو تعدّل EA الالتقاط V1.3.
- لا تضع ملف الأدلة في Common Files أو مجلد بيانات الإنتاج.
- الاختبار يقرأ الشموع فقط ولا يرسل أوامر تداول.

## 1) تنزيل ملف الاختبار

افتح ملف:
`D0_ReadOnly_CopyRates_Range_Diagnostic.mq5`

من GitHub:
`RUNTIME/MT5_RAW_CAPTURE_V1_3/tests/D0_ReadOnly_CopyRates_Range_Diagnostic.mq5`

استخدم زر Raw ثم احفظ الملف بالاسم نفسه.

## 2) وضع الملف في MT5

1. افتح نسخة MT5 التجريبية.
2. من القائمة File اختر Open Data Folder.
3. افتح مجلد `MQL5` ثم `Scripts`.
4. انسخ ملف `.mq5` إلى مجلد Scripts.
5. ارجع إلى MT5 وافتح MetaEditor بالضغط على F4.
6. من Navigator داخل MetaEditor افتح Scripts ثم الملف.

## 3) Compile

اضغط Compile أو F7.

- إذا ظهرت 0 errors، احتفظ بصورة لنتيجة Compile.
- إذا ظهر أي Error أو Warning، لا تشغّل الملف؛ أرسل صورة النتيجة كما هي.
- نجاح Compile محليًا لا يعني نجاح اختبار D0.

## 4) إعداد التشغيل

في MT5:
1. افتح Market Watch وتأكد من اسم الرمز كما يظهر حرفيًا عند الوسيط.
2. افتح Chart لهذا الرمز.
3. اسحب Script إلى الشارت.
4. اختر إطارًا واحدًا فقط من: M5 أو M15 أو M30 أو H1 أو H4 أو D1.
5. اختر فترة تاريخية مكتملة في توقيت خادم الوسيط الظاهر في المنصة؛ لا تفترض أنها UTC.
6. اجعل From أقدم من To، وتأكد أن الفترة لا تحتوي شموعًا مفتوحة.
7. اترك ArrayAsSeries = true في التشغيل الأول.
8. اضغط OK.

الأداة ترفض الحسابات غير التجريبية تلقائيًا. إذا لم يكن الحساب Demo فلن تجمع بيانات.

## 5) مكان ملف النتيجة

بعد التشغيل، افتح:
File → Open Data Folder → MQL5 → Files

ابحث عن ملف اسمه:
`D0_ReadOnly_<run-id>.csv`

لا تفتح الملف وتحفظه من Excel؛ احتفظ بالأصل دون تغيير.

## 6) ما ترسله للمراجعة

أرسل:
- ملف CSV الأصلي.
- صورة نتيجة Compile.
- صورة نافذة Inputs التي تبين الرمز/الإطار/From/To/ArrayAsSeries.
- صورة تبويب Experts بعد التشغيل.
- اسم الوسيط/خادم Demo، وإصدار MT5.

لا ترسل رقم الحساب أو كلمة المرور أو أي بيانات دخول.

## 7) معنى النتيجة

- PASS: تطابق الطلبان واستوفيا الشروط الأولية فقط؛ لا يعني اعتماد Recovery أو الإنتاج.
- FAIL: ظهر تعارض أو ترتيب غير صحيح أو شمعة غير مغلقة.
- INCONCLUSIVE: البيانات أو المزامنة أو أحد الشروط غير كافٍ.

لا تعِد تسمية نتيجة INCONCLUSIVE إلى PASS، ولا تحذف محاولة فاشلة. احتفظ بكل ملف دليل كما صدر.

## حدود الاختبار

هذا اختبار D0 فقط: تكرارية قراءة نطاق تاريخي واحد في حساب Demo. لا يثبت استرجاع الشموع بعد الانقطاع أو إعادة التشغيل، ولا يثبت هوية الشمعة الثابتة أو سلامة التخزين أو صلاحية توقيت UTC أو جاهزية التداول الحي.
