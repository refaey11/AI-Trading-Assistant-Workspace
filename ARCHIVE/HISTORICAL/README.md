# Historical Archive Policy

Files placed or classified here are retained for provenance and auditability, but are not current operational state.

## Read order
Always start with:
`PROJECT_STATE/CURRENT_STATE_INDEX_2026-08-22.md`

Then use historical artifacts only to understand provenance, reproduce tests, or verify how a decision evolved.

## Supersession rule
A historical file may be newer-looking in name or more detailed technically, but it cannot override a newer explicit decision for the same scope unless the current-state index is updated to promote it.

## Safety
Archive status does not mean delete or invalidate. It means: preserve, do not use as live state by default.
