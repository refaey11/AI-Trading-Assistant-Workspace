# RAF Coaching

This repository entry is reserved for the RAF Coaching rebuild requested by Karim.

## Product
Digital Personal Trainer / Online Coaching Platform as a mobile-first PWA.

## Core client areas
- Login and onboarding
- Home dashboard
- Today's workout
- Exercise details, animation/anatomy placeholder views
- Set tracking and workout completion
- Nutrition, meals, calories/macros, meal alternatives
- Water, steps, sleep
- Progress: weight, measurements, photos
- Weekly check-in

## Core coach areas
- Dashboard
- Clients and client profile
- Assessment
- Program builder
- Exercise library
- Nutrition
- Check-ins
- Notes/review/adjust program
- Approval workflow

## Coaching rules
- NASM/OPT-informed programming
- Individualized and progressive
- Regression before progression when technique/posture is inadequate
- Coach is final decision-maker
- No diagnosis; refer out when appropriate

## First exercise seed list
Squat; Bench Press; Incline Dumbbell Press; Lat Pulldown; Seated Row; Romanian Deadlift; Leg Press; Leg Curl; Lateral Raise; Dumbbell Curl.

## Design
Dark, premium, athletic, minimal, mobile-first. Green is reserved for actions/progress.

## Scope
Build the web/PWA MVP first. AI features come later. Do not modify or mix this work with the existing trading project logic.
